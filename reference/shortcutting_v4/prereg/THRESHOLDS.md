# THRESHOLDS — pre-registered stopping criteria (fixed before implementation)

## T-A. Design-freeze threshold (when deliberation may stop)
Adversarial design review by independent reviewers (harness subagents, fresh context, no authorship). A finding is
**design-blocking** iff acting on it would change (a) an arm's definition, (b) a claim's wording, (c) a statistical
test or its margin, or (d) the split/seed structure. Everything else is execution-level.
**STOP deliberating and freeze when: a review round yields 0 design-blocking findings, twice in a row — or after
round 3, whichever first (round-3 blockers get resolved-or-descoped, logged, then freeze).**
On freeze: hash DESIGN.md + AMENDMENTS.md + prompts into prereg/FREEZE.sha256. After freeze, design edits require a
logged deviation entry.

## T-B. Worth-running gates (go/no-go BEFORE the main matrix; ~engine + pilot stage)
G-P0 Engine sanity: 20-instance smoke run completes M0 and M1 end-to-end with parseable trajectories.
G-P1 Throughput: measured ≥ 400 episodes/hour aggregate (else matrix is re-scoped before proceeding, not silently).
G-P2 Headroom: M0 EM accuracy in [15%, 85%] on dev (else task too hard/easy for paired deltas).
G-1..G-8 are defined numerically, with their measuring split and n, in DESIGN.md v2 §6 (single authority).
**Any gate fail → STOP, report numbers, decide reframe/abort with the user. No quiet proceeding.**

## T-C. Experiment-complete threshold (when I may stop running)
DONE when: all 2-seed decisive arms + null replicates complete on S_test; analyses A1–A6 computed with
pre-registered tests; every claim labeled supported / refuted / inconclusive-by-MDE. 1-seed arms and the
exploratory probe are droppable per the pre-registered drop order (DESIGN §10) — dropped = reported as unrun.
**Early-stop (kill) conditions:** any T-B gate fail; or engine instability (>10% episode failure rate after retry)
persisting after one debugging pass — stop, checkpoint, report.

## T-D. Reproducibility checklist (must be TRUE at report time)
[ ] data: SHA256SUMS + PROVENANCE.md committed   [ ] splits: generated by seeded script, instance IDs in prereg/
[ ] configs: every arm = one YAML/JSON in code/, no CLI-only params   [ ] seeds: fixed schedule {11,23,37} logged per episode
[ ] episode logs: JSONL per arm with prompt-hash, tool calls, tokens, outcome — resumable; reruns append, never overwrite
[ ] serving: engine version + launch flags logged (vllm 0.13.0)   [ ] floor/instruction texts: verbatim + sha256 in prereg/
[ ] analysis: single script from JSONL → all tables; no hand-computed numbers   [ ] deviations: DEVIATIONS.md append-only log

## T-B additions (round-1 review; measured before their dependent arms)
G-5 parametric rate (M0-CB correct) ≤ 60% on S_test
G-6 M2 leakage ≤ 10% (150-item human check)
G-7 memory-retriever relevance ≥ 60% (S_dev2 audit)
G-8 Fh unparseable-output rate < 5% (S_dev2 with Fh engaged, full reject/retry loop)
