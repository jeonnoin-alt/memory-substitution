## What changed vs v3, and why (decision log)

1. **We no longer claim the phenomenon.** "When Agents Commit Too Soon" (arXiv:2606.22936, 2026-06) already names and diagnoses premature commitment in long-horizon agents via hidden-state convergence; "Quantifying and Mitigating Premature Closure in Frontier LLMs" (arXiv:2605.15000) establishes the bias vocabulary in single-turn/medical settings. This is good for us: the phenomenon's existence is independently established. Our claims are (a) a *manipulable cause* — answer-bearing retrieved experience — and (b) the *locus of repair* — control-flow enforcement vs the instruction slot. Neither paper manipulates memory or tests any repair.
2. **The evidence floor is a tool, not a contribution.** Evidence-sufficiency-gated commitment already exists as a budget-control policy (arXiv:2605.05701; POMDP framing in arXiv:2605.07042; self-verification evidence-seeking in arXiv:2512.22322). Novelty lives ONLY in the memory x enforcement interaction and the content decomposition. State this explicitly to preempt the "floors are known" review.
3. **New arm: the ANCHOR condition (reviewer-requested, accepted).** Inject the same plausible candidate answer framed as the model's *own tentative guess* (no memory framing, no retrieval provenance), token-matched. Pre-registered branch: if Anchor reproduces the truncation, the paper's title and framing change to "the candidate answer in context" (connects to LLM anchoring: arXiv:2412.06593, arXiv:2505.15392) and memory becomes one delivery vehicle among several; if Anchor does NOT reproduce it, the "record of past success" framing carries authority beyond the answer itself — a sharper and more surprising finding. Either branch is a paper; we commit to the branch logic in advance.
4. **Seeded dual optimizers stay; the bank-swap claim (v3 claim 4) is cut** and explicitly deferred to a separate study. GEPA and MIPROv2 are both seeded with the target instruction I* verbatim, so "the fix is in the search space" holds by construction and the budget objection (v2 reviewers A+B) is moot without 1200-rollout scaling runs.
5. **Scope = v2's, plus v3's two best inventions.** One environment (pooled multi-hop QA), banks A and A-redacted only, instructions I* and I_B (equal-burden control) only, enforcement ladder Fs / G(GEPA, seeded) / M(MIPROv2, seeded, reduced) / Fh. Non-echo dissociation vs experience-following (zero extra episodes) stays. Four-gate precheck stays, including the stored-record correctness audit (gate d) that separates us from adversarial-memory accounts (Proof-of-Execution Memory, arXiv:2608.16032; forged-reasoning attacks, arXiv:2607.05029). RB / RB+O ("is strategy memory safe *because* it omits answers?") is Extension E1, run only if Stage 1 completes early.
6. **Citation verification is a pipeline artifact.** Every cited arXiv ID ships in an appendix table: ID / exact title / two-sentence abstract quote / retrieval date / source (HF Papers, S2, arXiv). Reviewers of v3 (3/3) flagged unverifiable citations; post-hoc audit showed 30/30 were real — the failure was presentation, not honesty. v4 additions verified 2026-08-21: 14/14 real.
7. **Exploratory instrument (optional, appendix):** representational-commitment probes per arXiv:2606.22936 on a 200-episode subsample — does answer-bearing memory shift the hidden-state convergence step earlier? Zero new episodes (re-forward saved prefixes); marked exploratory, carries no claim.

## Short Hypothesis (v4)

When retrieved-experience memory breaks an otherwise-solvable task, the proximate cause is premature commitment: the agent treats a stored outcome as evidence about the current instance and stops gathering evidence early. Three testable consequences: (i) memory items carrying an OUTCOME cause the truncation; token- and keyword-matched answer-redacted items do not; (ii) the trigger is the presence of a usable candidate answer in context — tested directly by an anchor arm that injects the same answer as the model's own guess, with a pre-registered branch for either outcome; (iii) the repair belongs to control flow, not the instruction slot: a hard evidence floor removes most harm while preserving fixes, while the same requirement as a hand-written instruction, a GEPA-searched instruction (seeded with the requirement verbatim), and a MIPROv2-searched instruction each recover less than a third — and the citation-validity audit shows the searched instructions SAY it while the agent does not DO it (enforcement, not discovery).

## Experiments (design skeleton — no code until instructed)

HELD FIXED: ReAct + search tool over fixed corpus, retriever, step limit, bank frozen after construction, seeds, prompt boilerplate. Environment: pooled HotpotQA-distractor + MuSiQue + 2Wiki, n=500 paired test instances. Primary model Qwen2.5-14B-Instruct (vLLM, 4xA100); frontier API compliance probe on 120 instances x 4 arms (funded, not promised); Llama-3.1-8B decisive-arm replication at 1 seed.

PRECHECK GATES (150 dev instances, published either way): (a) bank fixes >=4% AND breaks >=4% vs no-memory; (b) no-memory compliance with I* >= 65%; (c) >=20% of induced errors are non-echo; (d) >=70% of items retrieved on broken instances are truthful records of correctly-solved tasks containing no verification claims.

ARMS. Memory axis: M0 none / M1 bank-A top-7 / M2 answer-redacted token+keyword-matched / ANCHOR (same candidate answer as own-guess framing, token-matched) — 2 seeds each. One-seed controls: M3 answer-only mirror / M4 decoy / M5 k=3 (the volume account; also the bridge to the sibling budget-confound study) / M6 step-budget control. Enforcement axis on {M0, M1, M2, ANCHOR}: bare / Fs (instruction only) / Fh (harness rejects unsupported answers, max +3 calls, fixed on dev, hash pre-registered). Optimizer arms: G1 = GEPA on instruction slot @ M1 (350 rollouts, seeded with I*), G0 @ M0; MIPROv2 @ M1 (350 rollouts, seeded, 1 seed). Instruction control: I_B (equal-burden, memory-orthogonal: list tools called in order) under M0 and M1.

INSTRUMENTATION per episode: tool calls before answer; distinct docs; evidence sufficiency; COMPLIANCE (semantic, defined under rewritten instructions); citation validity (anti-fabrication); memory-echo; confidence. Annotator: self-hosted Qwen3-32B validated vs 500-episode frontier gold + 200 human, kappa reported, demoted to supporting if kappa < 0.6.

ANALYSES. (1) descriptive mediation; (2) veto pattern comp(M0) ~= comp(M2) >> comp(M1) with M0-vs-M2 as TOST equivalence; where does ANCHOR fall — pre-registered branch; (3) non-echo dissociation vs Xiong et al. (arXiv:2505.16067): >=15pt compliance deficit persists on non-imitating episodes, null there is their win; (4) division of labour: break-reduction of Fs vs G1 vs MIPROv2 vs Fh at matched cost + evolved-instruction text + compliance audit (say-vs-do); (5) content ladder M1/M2/M3/M4 + volume M5; (6) interaction (M1-M1+Fh)-(M0-M0+Fh), MDE ~6pt at n=500x2.

BUDGET. ~19,000 self-hosted episodes (~115k calls, ~2 days on 4xA100) + 480 frontier probe episodes; API <= $180. Partial-completion: Stage 1 + Analyses 1-4 is the paper; Extension E1 (RB/RB+O) and the probe appendix run only on surplus; unrun = unrun, never null.

## Falsifiable predictions (compact)

P1 broken instances show >=1.5 fewer median tool calls vs their own M0 runs; fixed instances do not. P2 comp(M0)~=comp(M2) (TOST +-4) while comp(M1) collapses >=15pt. P3 ANCHOR branch pre-registered: (a) reproduces >=60% of M1's truncation -> title change to candidate-answer framing; (b) reproduces <30% -> provenance-authority finding. P4 Fh cuts breaks >=50% with fixes within 2pt; Fs, G1, MIPROv2 each recover <1/3 of Fh's reduction; G1/MIPROv2 write verification language yet compliance moves <10pt (say-do gap). P5 non-echo deficit >=15pt. P6 M2 keeps >=70% of fixes shedding >=50% of breaks; M3 breaks >= M1. P7 I_B does NOT collapse under M1 (else generic-burden account wins and veto framing dies). REFUTATIONS mirror each; if M5 (k=3) matches M1+Fh and M2 on every endpoint, the volume account subsumes ours and we report that.

## Known risks

R1 Anchor arm construction: the "own tentative guess" framing must not leak retrieval provenance; audited by a 100-instance human check. R2 If gate (d) fails, reframe to harm-from-imperfect-memory and say so. R3 Frontier probe may show high compliance at scale -> claim narrows to open-weight deployments, title amended. R4 [RESOLVED 2026-08-21, abstract-level full check via web]: SafeCommit (2608.04289, Akewar & Ranjan, FIU) is a risk-controlled layer between reasoning and execution that permits side-effectful actions only under a conformal certificate over plausible latent worlds, targeting premature commitment when memory grounding is STALE / CONFLICTING / INCOMPLETE / CORRUPTED. No collision with our three claims: it does not manipulate memory content (no redaction/decoy/token-matching), assumes imperfect memory (our gate (d) targets harm from CORRECT memory), and never compares enforcement against the instruction slot (no GEPA/MIPRO, no division-of-labour test). Reposition: cite as the repair-side engineering line whose premise (enforcement is the fix) our claim (iii) is the first to test against seeded instruction search. Adjacent same-trend systems to cite: MemAudit 2605.23723, SafeHarbor 2605.05704, non-malleable memory 2606.24322, safety risks of self-evolving agents 2604.16968.
