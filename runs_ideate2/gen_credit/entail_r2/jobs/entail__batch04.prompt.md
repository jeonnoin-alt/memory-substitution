### proposal: guilt_by_coretrieval
Title: Guilt by Co-retrieval: Measuring Reward Contamination of Learned Memory Utilities Against Leave-One-Out Ground Truth
Short Hypothesis: When an outcome reward is shared by all co-retrieved memory items, the learned utility of an innocent item is pulled toward the counterfactual value of whatever it is co-retrieved with (RoMeRL's memory-reward trap). We claim this contamination is a dose-response quantity that scrambles the ranking of items by their true intervention value: if the fraction of an item's retrievals that co-occur with a planted wrong-procedure item is randomised across items (dose 0, 0.5, 1), the rank correlation between learned per-item Q and leave-one-out (LOO) ground truth falls by at least the pre-registered minimum detectable effect (0.20 at n=120) although the items' own LOO value is unchanged; provenance-DAG credit (MemQ) and reduced-order utility coordinates (RoMeRL) recover at most a quarter of that loss because both still pool siblings retrieved for the same task, whereas a scorer that de-pools (flag-oracle, or LOO-corrected Q on a 20% subsample of stream episodes) recovers most of it, at a measured LLM-call cost. Contribution: the first measurement of learned per-item memory utilities against intervention ground truth under manipulated co-retrieval, giving the contamination slope, the failure of two published remedies against a reachable upper bound, and a costed fix.

Experiments:
- Ground-truth protocol (all cells): forced-retrieval intervention on the same (game, seed). Item i is forced into the k=3 set at rank 3 with the natural top-2 (composition i) or with a same-type W item at rank 2 (composition ii); 24 same-type evaluation games x 2 seeds = 48 pairs. Arms: WITH (i present) and REPLACE-static3 (i replaced by the type's static3 exemplar sentence padded to i's token count; Measurement C baseline, so per-item value is net of the static prompt by construction). Per-item value = mean paired success difference (SE ~0.10 at p=0.5); a 120-item class gives a class CI of about +/-2.6 net, 40 items about +/-4.5 net. Cost per item = 96 episodes; throughput 20 episodes/min on two replicas.
- Stream passes (E1; 673 unscheduled stream games run once = 0.6 h, plus 2,880 scheduled episodes per pass = 2.4 h): bank frozen (expert bank; W items enter only through the manipulation). Pass A: all B at dose 0. Pass A': dose 0, second stream and sampler seed (test-retest). Pass M1: dose randomised per item, 40/40/40 across {0, 0.5, 1}, stratified by tercile and task type. Pass M2: assignment rotated so each item gets a different dose than in M1. The rank-2 slot is replaced in every scheduled episode (W with probability d, else random same-type expert item), so dose changes wrongness only, not set size or churn. Logged per episode: retrieved ids, ranks, outcome, planted flag. Scorers fit offline per pass: per-item Q (count-average and alpha=0.1); MemQ TD(lambda in {0.5, 0.9}) over the retrieval DAG; RoMeRL-style per-task-type state (dim 4/16/64) updated by outcome, item utility = projection of the item embedding onto the state; usage-count and similarity-only controls; flag-oracle Q (B updated only from episodes without a W item). 4 x 2.4 + 0.6 = 10.2 h.
- Corrected-Q re-runs (on M1 scheduled episodes only, the episodes in which B items are updated): one REMOVE re-run per retrieved item (3 per episode) on a nested 10/20/40% subsample of all 120 items' scheduled episodes (3,456 episodes) and a 100% ceiling on a 40-item stratified subset (1,728 extra episodes); update rule: an item receives the outcome only if its removal flips success. 5,184 episodes = 4.3 h. Cost is measured (episodes, prompt and generated tokens per stream episode), not asserted.
- E0 Positive controls, run first. (a) W class (40 planted items, one per task type x layout, each swapping the target receptacle or omitting the clean/heat/cool step): clean-composition value <= -10 net, else contamination cannot be manufactured and the study stops (3,840 episodes, 3.2 h). (b) Scorer-validity gate within the B class alone: after the first 60 B items are ground-truthed, Spearman(pass-A per-item Q, LOO) over those 60 items >= 0.25 (SE ~0.12) and the A-vs-A' test-retest Spearman of Q vectors >= 0.5; W items are excluded from the gate so between-class separation cannot carry it.
- E2 Ground truth: composition (i) for all 120 B items (11,520 episodes, 9.6 h); composition (ii) for a 48-item stratified subset (4,608 episodes, 3.8 h); REMOVE (k=2) arm on 40 B items (1,920 episodes, 1.6 h) to report REMOVE minus REPLACE-static3. Report per-item and class values, split-seed reliability, Spearman(scorer, LOO) per pass with 1,000 item-level bootstraps, raw and disattenuated; the class-mean B value is stated against the measured k3 - static3 residual of +17.2 net.
- E3 Additivity, class level: 40 helpful+conflicting sets (B, W at ranks 2-3 with the natural rank-1) and 40 helpful+redundant sets (B, B' same type and procedure), each on 16 games x 2 seeds = 32 pairs, four arms (full, -B, -W or -B', -both). Interaction I = s_full - s_-B - s_-W + s_-both per set (per-set SE ~15 net), averaged per kind (SE ~2.4 net, CI about +/-5). 10,240 episodes, 8.5 h.
- E4 Decision cost: bottom-quartile (30 items) of each pass's Q vector crossed with clean LOO; dose composition of the pruned quartile; extra episodes and tokens per stream episode for corrected Q at each subsample rate versus the 100% ceiling.
- Budget: 673 + 11,520 + 5,184 + 3,840 + 11,520 + 4,608 + 1,920 + 10,240 = 49,505 episodes = 41.3 h at 20 episodes/min on two A100s, one vLLM replica per GPU, workers tuned to keep each replica's running queue >= 8; ground-truth cells run on one replica while the next pass runs on the other; nohup, pid files, resumable JSONL. Thresholds and the MDE are pre-registered before pass M1; if a 32-h cap is imposed, E3 drops to 30+30 sets and E2(ii) to 36 items, nothing else moves.

Baselines and Ablations:
- Scorer baselines (one per family): per-item outcome Q (REMEMBERER/MemRL style); MemQ-style TD(lambda) over the retrieval DAG; RoMeRL-style reduced-order coordinates; usage-count (no-outcome control); similarity-only rank (no-learning control); flag-oracle Q (reachable upper bound that de-pools with perfect information); LOO-corrected Q at 10/20/40/100% subsample (costed de-pooling).
- Ground-truth baselines: REPLACE-static3 (primary, Measurement C) versus REMOVE k=2 on 40 items; nested-k position contrast from runs/sweep/k_sweep_final.jsonl as the free position-level estimate and as the stratification variable for the B class.
- Composition: every per-item estimate reported under the clean and the W-containing composition on the 48-item subset; additivity tested in E3 at class level.
- Learning-rule ablations (offline, free): count-average versus alpha=0.1 Q; MemQ lambda in {0.5, 0.9}; RoMeRL state dimension {4, 16, 64}; corrected-Q subsample rate 10/20/40/100%; flip-only versus difference-weighted update.
- Placebo: the rank-2 slot is replaced in every scheduled episode, W or random same-type expert item, token-matched to the displaced item, so dose 0 has identical churn to dose 1.
- Test-retest: pass A' repeats pass A with a second seed; the A-vs-A' difference in Spearman(Q, LOO) is the noise floor every dose effect must clear.
- Removed: the self-written-item control (carried no prediction; cut to fit the envelope).

Falsifiable Predictions:
- P1 (headline) Contamination scrambles ranks: Spearman(per-item Q, clean LOO) over the 120 B items is lower in the mixed-dose passes (mean of M1 and M2) than in pass A by >= 0.20, the pre-registered MDE (analytic SE of a dependent-correlation difference at n=120 is ~0.08, giving 80% power at 0.20; the empirical A-vs-A' SE replaces the analytic one before M1 is scored and, if larger, the MDE is raised and stated). Falsified if the drop is < 0.10 with the item-bootstrap 95% CI excluding 0.20, or if the drop does not exceed the A-vs-A' test-retest difference. Arm: passes M1/M2 versus A, scored against E2(i). Not entailed: a shift common to all items of a dose group only reorders ranks if it exceeds the between-item spread of true value; if B items override the planted W at rank 2 (E2(ii) shows B's W-composition value close to its clean value) the W episodes carry no contamination and the correlation holds. The class-mean drop in B's Q with dose is reported only as a manipulation check, since it follows from E0(a).
- P2 Published remedies do not de-pool: on the mixed passes, MemQ TD(lambda) and RoMeRL coordinates each recover <= 25% of the P1 drop (their Spearman with LOO is within 0.05 of per-item Q), while the flag-oracle Q recovers >= 75%. Falsified if either remedy recovers >= 75% of the drop (Spearman >= per-item Q + 0.15) with CI excluding 25%; void (reported as such) if the flag-oracle itself recovers < 50%, which would mean the loss is not from pooling. Reachable mechanism for the falsifier: RoMeRL's projection can separate W from B if their embeddings load on different state directions, and MemQ with lambda=0.5 discounts multi-hop credit; both are run at three settings.
- P3 Costed fix, absolute: on M1, Spearman(corrected Q at 20% subsample, LOO) >= Spearman(Q, LOO on pass A) - 0.05 and >= Spearman(Q, LOO on M1) + 0.10, with recovery monotone in subsample rate. Falsified if the 20% scorer is <= per-item Q + 0.05 with CI excluding +0.10 while the 100% ceiling reaches pass-A level (the subsample is insufficient), or if the 100% ceiling itself stays below pass-A level - 0.10 (the estimator does not work at any cost). Cost is an estimand: measured extra episodes and tokens per stream episode at each rate, compared with a full LOO pass.
- P4 Non-additivity at class level: the class-mean interaction I is <= -10 net in helpful+conflicting sets and <= -10 net in helpful+redundant sets (single removals over-count), each with a 95% CI excluding 0; in redundant sets the mean single-removal effects are each > -5 net while the pair removal is <= -10 net. Falsified if the class-mean I is > -5 net with CI excluding -10 in either kind (additivity holds, so single-removal LOO is a fair estimator). Arm: E3, 40 sets per kind, SE ~2.4 net.
- P5 Decision consequence: in the mixed passes, dose-1 items make up >= 60% of the pruned bottom quartile (18 or more of 30; 10 expected under no contamination, binomial SE ~2.6), and the false-prune rate (bottom-quartile items with clean LOO >= +5 net) is >= 2x its pass-A rate, evaluated only if the pass-A rate lies in the pre-registered window [0.10, 0.45] where a 2x ratio is attainable. Falsified if dose-1 items are <= 13 of 30 in both mixed passes, or the rate ratio is < 1.3 with the paired-bootstrap CI excluding 2. Arm: E4 on passes A, M1, M2.
- P6 Gates (must pass before M1 is scored): E0(a) W-class clean value <= -10 net (CI +/-4.5); E0(b) within-B Spearman(pass-A Q, LOO) >= 0.25 over the first 60 ground-truthed B items and A-vs-A' Q test-retest >= 0.5. Either failure stops the confirmatory cells; the result is reported as a failed manipulation or an invalid scorer, not as a finding. The within-B gate can fail if the stratified B class has too little true spread or the reader ignores rank-3 items.

Measurement and Noise Control:
Paired design throughout: every intervention arm re-runs the same (game, seed) with the retrieved set changed only at the manipulated slot; env and sampler seeded per episode. Per-item LOO reliability is estimated by split-seed halves (Spearman-Brown corrected) and used to disattenuate scorer correlations; raw and corrected values are reported. Per-item Q is an average over 24 scheduled outcomes (SE ~0.10), matched to the LOO per-item SE; class cells: 120 items (~+/-2.6 net), 40-item subsets (~+/-4.5 net). The dose contrast is between-item within a pass and within-item across the two rotated mixed passes; correlation differences use 1,000 item-level bootstraps. Pre-registered MDE for P1: 0.20 at n=120, or the empirical A-vs-A' SE x 2.5 if larger. Test-retest of the learning pass (A vs A') is reported for every scorer; a dose effect must exceed it. Cost estimands: pairs per item to reach split-half LOO reliability 0.5, extra episodes and tokens per stream episode for corrected Q at each rate. Both GPUs stay busy by running E2 cells on one replica while the next pass runs on the other; throughput (episodes/min, tok/s per GPU) and queue depth are logged with each status update.
